# Основы CSS · простые элементы сайта

Учебная страница, собранная из базовых HTML-элементов. Вся задача — показать,
как простые теги выглядят в браузере и какие свойства CSS за ними стоят.
В коде много комментариев на русском, поэтому файл можно читать как шпаргалку.

## Что внутри

| Файл | Описание |
|---|---|
| `index.html` | Разметка страницы: шапка, навигация, 6 учебных секций, подвал |
| `style.css` | Стили, разбитые на 14 пронумерованных и прокомментированных блоков |

## Разделы страницы

1. **Текст и абзацы** — выравнивание, размер, регистр, подчёркивание
2. **Блоки и блочная модель** — наглядная схема `margin → border → padding → content`
   и три блока в ряд на `flex`
3. **Кнопки и состояния** — `:hover`, `:active`, `:focus`, `disabled`
4. **Списки** — маркированный, нумерованный, без маркеров
5. **Таблица** — `border-collapse`, `th`/`td`, подсветка строк через `nth-child`
6. **Форма** — текстовые поля, `textarea`, чекбокс, кнопка отправки

## Какие приёмы CSS разобраны

- переменные в `:root` и обращение к ним через `var(--name)`
- сброс `*` и `box-sizing: border-box`
- селекторы: по классу, по вложенности (`+`), по псевдоклассу
- `display: flex`, `gap`, `flex-wrap`, `flex: 1`
- `transition` для плавных изменений
- `box-shadow`, `border-radius`, `linear-gradient`
- медиазапрос `@media (max-width: 700px)` для адаптивности

## Как открыть

Никакой сборки и зависимостей — это статическая страница.

```
index.html
style.css
```

Достаточно открыть `index.html` двойным щелчком. Или запустить локальный сервер:

```bash
python -m http.server 8000
```

и перейти на http://localhost:8000

## Структура CSS

Файл разбит на блоки, чтобы в нём было легко ориентироваться:

```
 1. Переменные (:root)
 2. Сброс (нормализация)
 3. Шапка сайта
 4. Навигация
 5. Основной контент
 6. Текст
 7. Блочная модель
 8. Ряд из трёх блоков (flex)
 9. Кнопки, поля, ссылки
10. Списки и колонки
11. Таблица
12. Форма
13. Подвал
14. Адаптивность (медиазапросы)
```
