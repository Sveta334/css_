1. Текст и абзацы

Абзац — это тег <p>. Он по умолчанию имеет отступы сверху и снизу, поэтому абзацы не слипаются друг с другом.

Текст по центру: text-align: center

Текст по правому краю: text-align: right

Увеличенный текст: font-size: 24px

Верхний регистр: text-transform: uppercase

Подчёркнутый текст: text-decoration: underline

2. Блоки и блочная модель

У каждого блока есть margin (отступ снаружи), border (рамка), padding (отступ внутри) и сам content (содержимое). Это и есть «блочная модель» (box model).

3. Кнопки и состояния

Кнопка меняется при наведении — это псевдокласс :hover. Нажатая — :active. В фокусе — :focus.

4. Списки

Маркированный (по умолчанию)

  • Первый пункт
  • Второй пункт
  • Третий пункт

Нумерованный

  1. Первый пункт
  2. Второй пункт
  3. Третий пункт

Без маркеров

  • Пункт без точки
  • Используется для меню
  • Или для навигации

5. Таблица
